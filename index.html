1) 이용대상별 현황 (단위 : 명)
전체 이용대상별 현황

교육문화 프로그램 항목 입력

기존 구분을 선택하거나, 새 교육문화 구분과 새 프로그램을 이 자리에서 바로 만들 수 있습니다.

입력 방식 선택

새 교육문화 구분·프로그램 구성

구분이 아직 정해지지 않은 신규 교육문화 강좌는 여기에서 새 구분을 만든 뒤 프로그램명을 지정해 저장합니다.

교육문화 구분·프로그램 관리

목록만 먼저 정리하거나 삭제할 때 사용합니다. 이미 실적이 입력된 구분/프로그램은 삭제할 수 없습니다.

3) 교육문화 프로그램 등록현황 (단위 : 명)

특별 프로그램 운영현황 입력

기존 분야를 선택하거나, 새 분야와 새 사업명/연계명을 이 자리에서 바로 만들 수 있습니다.

입력 방식 선택

새 분야·새 사업명 구성

분야가 아직 정해지지 않은 신규 특별 프로그램은 여기에서 새 분야를 만든 뒤 사업명/연계명을 지정해 저장합니다.

특별 프로그램 분야·사업명 관리

목록만 먼저 정리하고 싶을 때 사용합니다. 이미 실적이 입력된 항목은 삭제할 수 없습니다.

※ 입력값이 없어도 전체 분야·사업명 목록이 먼저 보입니다.
